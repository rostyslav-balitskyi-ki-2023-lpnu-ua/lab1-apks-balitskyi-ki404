**Студент:** Баліцький Ростислав Богданович
**Група:** КІ-304
**Варіант:** 2 (Python, venv + скрипт запуску, pytest)

## Опис проєкту
Цей проєкт містить кросплатформний застосунок "Hello World" на Python та спеціалізованого AI-агента. Агент автоматизує процес генерації коду, налаштування системи складання, тестів та GitHub Actions.

## Запуск агента
Для запуску агента та перевірки використовується оркестратор (команда `init`). Точна інструкція буде додана після налаштування AI-клієнта.
