# Архітектура AI-агента

## Які проблеми вирішує агент
Агент автоматизує рутинні задачі з налаштування проєкту: створення базової структури кросплатформного проєкту на Python, налаштування віртуального середовища, генерацію юніт-тестів (pytest) та створення CI/CD pipeline (GitHub Actions) для Windows, Linux та macOS.

## Використані skills
1. **project-scaffold**: створення мінімального Hello World-проєкту, README, структури каталогів та .gitignore.
2. **build-and-test**: створення скриптів запуску, тестової функції та юніт-тестів.
3. **github-actions**: створення .github/workflows/ci.yml із матрицею для трьох ОС.

## Доступні commands
- `git-init`: перевіряє стан Git та генерує/оновлює .gitignore.
- `create-project`: викликає project-scaffold для створення проєкту.
- `create-build`: викликає build-and-test для конфігурації тестів.
- `create-actions`: викликає github-actions для CI workflow.
- `check`: перевіряє структуру, конфігурацію, складання та тести (без зміни проєкту).
- `init`: оркестратор, що послідовно запускає git-init, create-project, create-build, create-actions та check.

## Передача даних між етапами
Кожен етап (command) спирається на результати попереднього. `git-init` створює чистий стан репозиторію, `create-project` генерує код у ньому. `create-build` додає тести до наявного коду, а `create-actions` створює workflow для перевірки згенерованого проєкту. Дані передаються через стан файлової системи.

## Обробка помилок оркестратором
Оркестратор (`init`) перевіряє код повернення кожної підкоманди. Якщо будь-який етап (наприклад, генерація коду або перевірка `check`) завершується з помилкою, оркестратор зупиняє виконання всього ланцюжка і виводить повідомлення про помилку, не переходячи до наступного кроку.
